# AutoRent — система аренды автомобилей

## О проекте

AutoRent — учебное веб-приложение для просмотра автомобилей и демонстрации основных возможностей системы аренды транспорта.

Проект разработан на ASP.NET Core MVC с использованием Entity Framework Core и базы данных SQLite.

## Возможности

- Просмотр каталога автомобилей.
- Фильтрация автомобилей по параметрам.
- Просмотр подробной информации об автомобиле.
- Регистрация и авторизация пользователей.
- Хранение данных в базе SQLite.
- Начальная загрузка демонстрационных автомобилей и справочников.

## Запуск проекта

### Вариант 1. Автоматический запуск в Windows

1. Скачайте или скопируйте папку проекта.
2. Откройте папку `AutoRent-College`.
3. Запустите файл `Запустить-AutoRent.bat`.
4. Дождитесь запуска приложения.
5. Откройте в браузере:

   http://localhost:5016

### Вариант 2. Через терминал

Откройте терминал в папке, где находится `AutoRent.csproj`, и выполните:

```powershell
dotnet restore
dotnet run --urls http://localhost:5016
```

После запуска откройте http://localhost:5016.

Чтобы остановить приложение, нажмите `Ctrl+C` в терминале.

## Структура проекта

- `Controllers/` — MVC-контроллеры.
- `Models/` — модели данных и ViewModel.
- `Views/` — Razor-представления.
- `Data/` — контекст базы данных и начальное заполнение.
- `Migrations/` — миграции Entity Framework Core.
- `wwwroot/` — CSS, JavaScript и статические файлы.
- `Program.cs` — конфигурация и запуск приложения.

## База данных

Используется SQLite. Файл базы данных называется `AutoRent.db`.

При первом запуске приложение применяет миграции и инициализирует необходимые данные, если это предусмотрено текущей конфигурацией.

Не публикуйте личные данные тестовых пользователей и рабочие секреты в репозитории.

## Статус проекта

Учебный проект. Основная цель — демонстрация работы веб-приложения каталога автомобилей с регистрацией пользователей и хранением данных.
